# Benchmark results

One file per submission, named `<yyyy-mm-dd>-<github-handle>-<software>.md`, for example
`2026-10-20-jdoe-freecad.md`. Copy [`TEMPLATE.md`](TEMPLATE.md) and fill it in. One file can hold
several models, as long as they were run on the same machine with the same software.

Publish only results you are allowed to publish: some commercial software licences forbid
publishing benchmarks.
